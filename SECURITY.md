# Security

## Reporting a vulnerability

**Please do not** open a public issue for security-sensitive bugs.

Use **[GitHub Security Advisories (private report)](https://github.com/vercel-labs/nuxt-websockets-starter/security/advisories/new)** so maintainers can assess and release a fix responsibly.

Include:

- A clear description and impact
- Steps to reproduce or a minimal code sample, when safe to share
- Whether the issue involves the WebSocket upgrade, message handling, or Redis state

We will triage reports as soon as we can. Thank you for helping keep users safe.
